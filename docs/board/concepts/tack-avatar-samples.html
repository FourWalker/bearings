Tack avatars: design samples

Tack becomes a small pixel character that lives on the Assistant's pill and perches on top of the chat window. Each skin is one sprite sheet with the same set of states, played at 2–8 fps with no in-between frames. The first skin is the Claude character, in Claude terracotta. Samples only, nothing is built yet.

2 · Live mock (click, type and send)

Leave the pill alone for 6 seconds and Tack falls asleep. Click it to wake Tack and open the chat. Typing makes Tack read along, and sending makes it think. Ask it to "add a task for login bug" to see it write a note and pin it to the board.

3 · Customization

A suggested settings section, at Settings › Board › Assistant. Every skin uses the same state names, so adding a skin only means adding a sprite sheet and a small manifest.

Calm keeps only the one-shot reactions (wake, note, done) and holds a still frame otherwise. Still shows a fixed pose per state. The OS's reduced-motion setting picks Still automatically.

4 · Sprite sheets

Every frame as it would be exported: a 26×20 pixel cell per frame, one row per state. In the app, a sheet is played with CSS steps(), so no JavaScript timer runs and nothing repaints while Tack sleeps.
