Tree view: module deck, sort, hide done, name search

The Tree view opens as a wall of fully open notes. This concept shuts them into a deck: each module shows one line (name and status) and the next card sits on its edge. A bar under the header hides done work, orders the cards and filters by name. A star on a feature, module or task moves it to the front, and a once-a-day review keeps the stars from piling up. Try it below: click a card's line to open or shut it. Nothing is built yet.

How it behaves

The deck. Modules in a column are shut by default: one line each with the dot, the name, a status stamp (Working, Needs you, Blocked, Paused, Done) and tasks done / total. Click the line to open the card in place; any number can be open. In an open card, clicking the body opens the task as today; the arrow shuts it.
Master note. Shuts to the same one line. "Open all / Shut all" in the bar acts on every card. Which cards are open is remembered per board on this device.
Show done. Off by default: done modules and done tasks are left out, and each column says how many ("3 done hidden", click to show). On: they come back, dimmed, with their done time.
Order. Applies to modules in a column and to tasks in a module. The arrow reverses it. Columns themselves keep today's order (most recently changed first).
Filter by name. Matches titles of masters, modules and tasks as you type. A match keeps its parents; a module with a matching task opens and shows only the matches. Done items match too only when Show done is on.
Stars. A star on any card line or task row (also in the open task's header). Starred comes first whatever the order: a starred feature's column moves left, then columns holding a starred module or task; a starred module rises to the top of its deck, a starred task to the top of its module. Among starred, the chosen order applies.
Starred filter. "★ Starred" in the bar shows only starred items with their parents. A starred feature shows its whole column. It combines with the name filter and Show done.
Daily star review. Once a day, after the first save on the board (an edit, a plan, a handoff, a decision, a new task), a dialog lists every star, ticked. Finished ones are on top, marked Suggested. Untick and Save to unstar; Keep all shuts it. It does not show when nothing is starred, and never twice in a day.
Don't ask me again. Ticking it turns the review off on this device. It comes back from Board settings, "Daily star review", which also has "Review stars now".
Remembered. Order, direction and Show done are kept per board on this device, so the board reopens the way you left it. The name filter is not kept.

What gets saved

Field on task.jsonStamped whenCleared whenOld tasks
lastActionAtA plan step or item is ticked or unticked, the status changes, or a last-action line is written (checkpoint, handoff, update, turn end). By a person or an agent.NeverFalls back to the last-action line's time, else updatedAt
doneAtA tick leaves no unticked step in the plan (the last tick), or the status is set to done, whichever comes first. A done child that ticks its parent's last step stamps the parent too.A step is unticked or the task is reopenedDone tasks fall back to their done evidence time, else updatedAt

starredAt (a time, missing when not starred) is saved on the task too, so a star is the same on desktop, in the browser and for an agent reading the board. The review's "last shown" day and "Don't ask me again" are kept on the device.

Both fields are optional, so the Claude Code mod and older builds keep reading the same files. updatedAt is not reused for "last action": it also moves when a chat links, a file is recorded or a title is edited.

For you to decide

  1. Last tick and status. The last tick stamps the done time but leaves the status as it is (an agent or you still mark it done). Or should the last tick also set the status to done?
  2. What opens by itself. Everything shut on first open. Or should a module that is Working or Needs you start open?
  3. Columns. Should the order also sort the master-task columns, or only what is inside them (as drawn)?
  4. What triggers the review. I read "first Confirmed or Saved button" as the first thing you save on the board that day, shown right after the save goes through. The other reading is the first time the board is opened that day. Which one?
  5. Suggested stars. Drawn ticked, so you untick them yourself. Or should finished ones come already unticked, so Save alone clears them?
  6. Where a star lives. On the task file (shared by every device and visible to agents), as drawn. The Pin is per device; a star could be too.
  7. Other views. This covers the Tree view only. Level 1/2/3 and By service keep their look; the name filter and order could be added there later.
  8. Mobile. Gets the two new times over the wire; its board screen is not changed in this step.
